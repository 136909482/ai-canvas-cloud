## 已完成能力

### Cloud 基础

- 普通账号使用全局唯一且不可修改的用户名、邮箱和密码；支持用户名/邮箱登录、单活跃 session、设备历史、邮箱验证/密码重置和 personal workspace，普通界面不上传或读取图片头像。
- 关系化项目图、ID 级 diff、幂等批次、乐观版本冲突、手动/定期 checkpoint 和历史恢复。
- 私有图片/视频资产、预签名上传、服务端 metadata 校验、配额、引用/checkpoint 保护，以及后台聚合预检与二次确认的 7 天延迟 GC。
- 版本化目录包的 prepare、暂存、copy/replace commit、进度重试和导出。
- 普通 API 的 CORS/CSRF/严格 JSON/Redis 限流、两账号授权边界、健康指标和脱敏诊断。

### Admin

- 独立 Admin Origin、Cookie、Better Auth Secret、数据库角色、`admin` schema、RBAC、可选验证码和不可修改审计。
- 版本化网站设置、Logo/Favicon 受控上传、公开最小投影。
- 用户列表/详情、封禁、解封、session 撤销，以及注册、生成请求/结果/质量、存储和依赖健康聚合。
- 超级管理员可测试、版本化发布、即时启停全站 SMTP；凭据使用独立部署密钥加密，普通验证/重置邮件按 revision 动态生效。
- 超级管理员可在不查看用户文件明细的前提下扫描并清理无引用 OSS 资产，操作只记录聚合审计。
- `super_admin` 与 `operator` 可创建、编辑、发布和下线全站通知；用户通知中心合并本地运行消息与云端未读公告，并提供可回看的发布时序时间线。
- Admin 不读取项目正文、Prompt、资产内容/object key、session token 或浏览器 Provider 配置。

### 浏览器本地生成

- 独立室内设计节点 V1 已落地：单张模型图输入、六套原创光影预设、完整室内参数、确定性只读 JSON 编译，以及复用现有浏览器图片 Provider、任务队列、独立结果节点和 Cloud 资产入库链路；景观设计与建筑设计节点仍未开始。
- 加密设备 Vault v2：Provider、独立 Key 槽、模型条目和匿名绑定；本地任务缓存只接受 v3，并加密暂存待入云图片结果。
- 受控 OpenAI Compatible/DashScope chat、image、video 协议；平台不代理 Provider，也不接收用户 Key/endpoint/真实模型 ID。
- 服务商模型发现、服务商下模型管理、节点按模型分组并选择具体服务商路由，以及不可执行状态提示。
- 云端图只保存 `local:<uuid>`，新设备由用户显式绑定，不自动按名称或上游 ID 替换。
- 画布管理和外观设置的九项非敏感偏好按账号与工作区同步；旧本地配置只在云端未初始化时迁移，Provider Vault 与本地任务继续保持设备隔离。
- 统一浏览器任务中心按 FIFO 原子领取任务，图片并发 8、视频并发 1；同步/异步图片走受控 adapter，同一节点每次生成独立结果，异步任务和待入云结果可在同设备恢复。
- 媒体结果经 Cloud 资产上传和幂等图变更入云；Provider POST 不自动重试，轮询 GET 有限退避，上传失败不重新生成。Provider 私有配置、绑定指纹、任务阶段、remote task ID 和临时 Blob 均不进入 Cloud。
- 文本/图片/视频调用发送不含 Provider 私有信息的有限 attempt 遥测，Admin 按上海自然日展示今日 KPI、7 日趋势、运行质量和失败分类。

功能实现已完成：用户运营、生成运营仪表盘、带原因的账号操作、session 撤销、审计、服务商模型发现和节点模型选择均已落地。

- 用两个账号和两个独立浏览器存储上下文复核 Cloud 资源、Vault、任务缓存和匿名绑定隔离。
- 在桌面与 390px 视口复核注册用户名校验、用户名/邮箱登录、个人资料及关键用户/Admin 流程，无横向溢出、控件遮挡或控制台错误。
- 使用真实公网 SMTP 完成连接、测试投递、验证邮件、密码重置、停用/重启用和密钥轮换验收。
- 准备真实 `infra/deploy/staging/staging.env` 和可用 Docker 环境，运行 staging 配置门禁、部署、备份与隔离恢复演练。

## P9：生产灰度与正式上线

P8-8 完成后才进入 P9。交付范围：

- 正式域名、HTTPS、Web CDN、API/Admin、PostgreSQL、Redis、私有对象存储和邮件服务。
- 平台密钥管理、环境隔离、邀请/灰度开关、存储配额和紧急停写能力。
- 站内用户协议、隐私政策、帮助中心、问题反馈和注册强制同意已落地；正式上线前仍需运营主体完成法律审校，并补齐数据导出、账号删除、备案、内容安全与适用合规检查。
- 发布、回滚、故障公告和责任人流程。

上线门槛：

- 两个真实账号在不同浏览器完成端到端隔离验证。
- 生产浏览器生成不依赖 Vite 代理，用户 Key 只存在设备 Vault，Cloud 请求不携带 Provider 私有配置。
- 自动备份、隔离恢复和对象误删恢复策略验证通过。
- 同设备异步恢复、页面中断、失败重试和结果上传幂等通过。
- 应用回滚能读取发布前数据；不可逆 migration 不与首发应用同时发布。
